/*
 * Custom Data Type: Task
 * Description: Generic task/work item structure for task management
 * Created: Template
 */

Task CDT Structure:
- id (Integer) - Unique identifier for the task
- title (Text) - Task title/summary
- description (Text) - Detailed task description
- status (Text) - Task status (New, In Progress, Completed, Cancelled)
- priority (Text) - Task priority (Low, Medium, High, Critical)
- assignedTo (User) - User assigned to the task
- createdBy (User) - User who created the task
- createdDate (Date and Time) - Task creation timestamp
- dueDate (Date) - Task due date
- completedDate (Date and Time) - Task completion timestamp
- category (Text) - Task category/type
- estimatedHours (Number) - Estimated hours to complete
- actualHours (Number) - Actual hours spent
- attachments (Document) - Task-related documents (multiple)
- comments (Text) - Task comments/notes (multiple)
- parentTask (Task) - Parent task reference for subtasks
