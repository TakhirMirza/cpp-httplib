/*
 * Custom Data Type: User
 * Description: Standard user information structure for the application
 * Created: Template
 */

User CDT Structure:
- id (Integer) - Unique identifier for the user
- username (Text) - User's login username
- firstName (Text) - User's first name
- lastName (Text) - User's last name
- email (Text) - User's email address
- phone (Text) - User's phone number
- department (Text) - User's department
- role (Text) - User's role/position
- isActive (Boolean) - Whether the user account is active
- createdDate (Date) - Date when user was created
- lastLoginDate (Date and Time) - Last login timestamp
- profilePicture (Document) - User's profile picture
- manager (User) - Reference to user's manager (nested CDT)
